# Парсер сайта в Excel

Демо-проект: скрипт на Python собирает каталог товаров с сайта и сохраняет его в аккуратную Excel-таблицу.

Для примера используется **books.toscrape.com** — учебный сайт-магазин, созданный специально для тренировки парсинга (1000 книг на 50 страницах).

## Что умеет

- Сам проходит по всем страницам каталога
- Собирает название, цену, рейтинг, наличие и ссылку на товар
- Сохраняет в Excel: оформленная шапка, фильтры, закреплённая первая строка, кликабельные ссылки
- Отдельный лист «Сводка»: количество товаров, средняя, минимальная и максимальная цена
- Пауза между запросами, чтобы не нагружать сайт
- Повторяет запрос при сбое сети

## Технологии

- Python 3
- requests — загрузка страниц
- BeautifulSoup — разбор HTML
- openpyxl — создание Excel-файла

## Установка и запуск

```bash
pip install -r requirements.txt
python parser.py
```

Результат появится в файле `books.xlsx` рядом со скриптом.

## Как переделать под другой сайт

Достаточно поменять адрес в `START_URL` и CSS-селекторы в функции `parse_books()` — остальное (обход страниц, Excel, сводка) остаётся без изменений.
